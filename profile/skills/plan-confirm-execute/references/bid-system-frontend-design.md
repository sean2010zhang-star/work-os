# 评审系统前端设计规范

## 布局要求

### 左侧导航栏 (非顶部Tab)
用户明确要求: "左边应该有个导航栏"，不要用顶部Tab切换。

```
┌──────────┬─────────────────────────────┐
│ Sidebar  │  Main Content               │
│ (fixed)  │  (scrollable)               │
│ w-60     │  ml-60 px-8 py-6            │
│ ──────── │                             │
│ 品牌Logo  │                             │
│ ──────── │                             │
│ ① 步骤1   │                             │
│ ② 步骤2   │                             │
│ ③ 步骤3   │                             │
│ ④ 步骤4   │                             │
│ ──────── │                             │
│ 📁 历史   │                             │
│ ──────── │                             │
│ 状态统计  │                             │
└──────────┴─────────────────────────────┘
```

### Step状态机
- completed: 绿色checkmark，可点击回到
- current: 蓝色高亮，带描述
- unlocked: 灰色，可点击(上一步已完成)
- locked: 深灰色，不可点击

### 多文件上传模式
每个实体(供应商/投标人)一个卡片:
- 卡片头: 实体名称 + 关键属性(报价等)
- 卡片体: 文件列表，每个文件有类型选择(技术标/商务标/整体标)
- 支持添加/删除文件
- 上传后自动识别关键信息(名称/报价)，显示"自动识别"标记

### 自动识别交互
- 从文档解析文本中用正则提取关键字段
- 提取成功 → 绿色边框 + "自动识别"标记
- 用户手动修改 → 标记消失，以用户输入为准
- 仅在字段为空时自动填充，不覆盖已有输入

## FlowForge暗色主题
- 背景: bg-[#0e1416]
- 侧边栏: bg-[#0a0d10]
- 卡片: bg-white/[0.03] border-white/10
- 输入框: bg-white/[0.03] border-white/10 text-gray-200
- 文字: text-gray-100/200/300/400/500/600
- 强调: blue-600, purple-400, green-400, red-400
