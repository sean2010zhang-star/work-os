# 方案确认四问模板

## 使用场景
当用户说"按方案确认三步走"时，按以下结构快速确认：

## 四问格式
```
按方案确认三步走，需要你确认：

1. [问题1] 还是 [问题2]？
2. [问题3]，还是 [问题4]？
3. [问题5] 还是 [问题6]？
4. 通知发到哪里（[选项A]/[选项B]/[选项C]）？
```

## 回答处理
用户一次性确认所有项，如：`全部确认用A，报告发到我邮箱`
→ 无需逐项确认，按用户指示执行

## 示例：AI协同自动化方案确认
```
1. Phase 1先做（Auto-Router），还是一次性做完4个phase？
2. 多agent用Hermes tmux进程，还是Claude Code作为编码专项？
3. 审计标准用默认模板，还是由你来定义具体标准？
4. 通知发到哪里（邮件/IM/笔记工具）？
```
用户回答：`一次性都做完，多agent用Claude Code作为编码专项，审计标准用默认模板，报告发邮箱`
