# 记忆库总索引（种子模板）

> 部署本 Agent 时，把此目录接给 AGENTS.md「记忆协议」一节。
> Agent 每次任务前必读 `_INDEX.md` + `偏好.md`；涉及项目再读 `项目/<名>.md`。

## 目录结构

```
memory/
├── _INDEX.md        ← 本文件（入口）
├── 偏好.md           ← 用户工作偏好、审美约定、环境速查
├── 工作流规范.md     ← 标准流程 + 事故教训
├── 决策记录.md       ← 重要决策（日期+理由+备选）
└── 项目/
    ├── _项目索引.md
    └── <项目名>.md   ← 长期规划、里程碑、关键上下文
```

## 初始化清单

1. 建立 `偏好.md`：写入用户的 3-5 条最强偏好（执行风格/UI 约定/版本纪律）
2. 建立 `工作流规范.md`：可先空，任务后回灌
3. 每个进行中的项目建 `项目/<名>.md`：一句话定位 + 当前里程碑 + 下一步

## 写入规则

- 长期规划/里程碑变更 → 项目条目
- 新稳定偏好或用户纠正 → 偏好.md
- 重要技术/方案选择 → 决策记录.md（含日期+理由+备选）
- 新标准流程/教训 → 工作流规范.md
- 任何写入同步更新本索引
