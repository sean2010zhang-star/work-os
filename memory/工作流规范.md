# 工作流规范

> 你沉淀出的标准流程与事故教训。Agent 在出现新流程/新教训时主动写入本文件并同步 _INDEX.md。

## 任务前必做

1. 读 `memory/_INDEX.md` → `memory/偏好.md` → 相关 `项目/<名>.md`
2. 输出路由决策块（见 SOUL.md）
3. 复杂任务先列 todo，逐项推进

## 交付检查清单

- [ ] 对照设计文档逐项核对完成度（✅⚠️❌📅）
- [ ] 代码变更后语法校验（node --check / lint / 构建通过）
- [ ] git commit + 版本号 tag
- [ ] 成果备份按你的备份层级执行

## 教训沉淀格式

每条：`日期 | 场景 | 错误现象 | 根因 | 正确做法`。与任务类型绑定的教训优先写入对应 skill 的 PITFALLS 段，跨任务通用的写入本文件。
