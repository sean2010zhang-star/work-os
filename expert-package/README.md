# 入驻包说明 — Work OS 纪律型项目总管（WorkBuddy 自定义专家）

WorkBuddy「企业专属专家」= 岗位说明书 + SOP + 知识库。本目录三件套对应上传：

| WorkBuddy 要素 | 本包文件 | 说明 |
|----------------|----------|------|
| 岗位说明书 | `岗位说明书.md` | 角色定位+5铁律+工作协议+输出标准+边界，可直接粘贴 |
| 标准作业流程(SOP) | `../plugins/work-os/skills/` 精选 4 份 | work-os-router / sprint-with-tiers / delivery-audit / consolidated-iron-laws 的 SKILL.md |
| 知识库 | `../plugins/work-os/skills/` 全 8 份 + `../memory/` 种子 | 方法论全貌+方案模板+陷阱库+审计清单 |

## 上传步骤（WorkBuddy 企业版路径）

1. 管理后台 → 专家市场/自定义专家 → 新建企业专属专家
2. 岗位说明书：粘贴 `岗位说明书.md` 全文
3. 知识库：把 `skills/` 8 个目录逐个打包上传（WorkBuddy 支持 SKILL.md 格式时可直接导入；不支持则转 PDF/MD 作知识附件）
4. 调试：用三个测试任务验证——①小查询（应直接给结果）、②中型功能（应先出方案）、③"帮我看看这个项目完成没有"（应逐项报完成度而非笼统说完成）
5. 发布到团队

## 差异化卖点（填平台介绍栏用）

> 别的专家"会干活"，这个专家"敢验收"。每条铁律都来自一次真实事故的教训，
> 交付必附证据包，完成度诚实申报——适合把 Agent 用在正经项目上的团队。
