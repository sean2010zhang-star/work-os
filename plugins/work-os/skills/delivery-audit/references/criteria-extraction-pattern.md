# 招标文件标准提取增强模式

> 从招标文件中提取评审标准(资格审查+评分细则+项目要求)的工程实践

## 问题

默认关键词匹配太窄，真实招标文件用词多样：
- "营业执照" 也可能写作 "工商执照"、"法人营业执照"
- "项目经理" 也可能叫 "项目负责人"、"技术负责人"

## 三层提取策略

### Layer 1: 扩展关键词匹配
每项资格审查配6-8个同义词：
```python
{"name": "项目经理", "keywords": [
    "项目经理", "PMP", "信息系统项目管理师",
    "高级项目经理", "项目负责人", "技术负责人"
]}
```

### Layer 2: 文档章节动态提取
从"资格审查/符合性审查"章节自动提取：
```python
# 识别审查章节边界
if "资格审查" in seg: in_review_section = True
if "评分标准" in seg: in_review_section = False

# 在审查章节内提取"具有/持有/提供/具备"模式
action_match = re.search(r"(具有|持有|提供|具备)(.{2,30})", seg)
```

### Layer 3: 表格评分规则解析
从文档表格中提取评分项：
```python
# 匹配列头
for i, cell in enumerate(header):
    if "分值" in cell: score_col = i
    if "内容" in cell: name_col = i
    if "标准" in cell: rule_col = i

# 正则提取分值
score_match = re.search(r"(.{2,30})[（(]?(\d+)[）)]?\s*分", line)
```

## 前端展示：表格格式

评分细则必须用表格展示（不是树形/JSON），方便用户核对：
```
| 评分维度 | 评分项 | 满分 | 评分规则 |
|----------|--------|------|----------|
| 项目经理(3分) | PMP证书 | 2 | 持有PMP得2分 |
|              | 年限+同类 | 1 | >=5年且有同类 |
```

文档提取的评分项独立展示(绿色标记) + 核对提示：
"💡 以上为从招标文件中自动提取的评分项，请核对是否完整准确"
